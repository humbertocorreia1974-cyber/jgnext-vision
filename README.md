# 🚀 JGNext Vision

> Plataforma SaaS de monitoramento de segurança eletrônica com IA self-hosted sobre câmeras já existentes do cliente (RTSP/ONVIF), central de eventos e alarmes com workflow de operador, portal do cliente, e ERP de campo embutido (ordens de serviço, técnicos e estoque em comodato).

## 🛠️ Como Executar Localmente

```bash
# 1. Instalar dependências
npm install

# 2. Configurar variáveis de ambiente
cp .env.example .env # se aplicável

# 3. Iniciar servidor de desenvolvimento
npm run dev
```
